# 战术战棋

小地图战术战棋框架：3D 斜俯视方格盘 + 2D 占位单位。Godot 4.6。

## 运行

```bash
bash tools/install_godot.sh   # 若 PATH 无 godot
bash tools/run_light_verify.sh
godot --path .
```
