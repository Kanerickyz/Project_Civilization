# 湖泊 / 树林 · 成簇开局

> **已实现**（轻量切片）。类型在 `resources/terrain/`；开局由内部 seed 成簇写入棋盘。

## 玩家能看到什么

- 进入沙盘后，棋盘上除草地外可能出现**湖泊**（偏蓝水面）与**树林**（深绿 + 树冠标记）。
- 每局比例与位置不同（同局内可复现：固定内部 seed）。
- 主菜单不再提供地图编辑入口。

## 地块规则

| id | 显示名 | 可通行 | 攻击 | 燃烧 |
|----|--------|--------|------|------|
| `lake` | 湖泊 | 是 | 不挡 | 湖格不点燃；其上单位不受燃烧施加；**进入湖格清除**该单位燃烧层数 |
| `forest` | 树林 | 否 | **挡攻击**（视线中间格） | 同墙：不可站人，不叠燃烧玩法 |

- 与既有 `grass` / `wall_straight` 并存；本切片生成器只铺湖与林，不自动铺墙。
- 攻击挡线：攻击者与目标之间的中间格若有 `blocks_attack` 地块（树林），则不可普攻/加强攻/燃爆攻。切比雪夫距离 1（邻格）不挡。城墙仍不挡射击。

## 开局生成

| 项 | 约定 |
|----|------|
| 触发 | 每局进入沙盘建盘时 |
| Seed | 内部随机整数，不暴露 UI |
| 湖占比 | 独立掷在 **0%–15%**（相对全盘格数，四舍五入） |
| 林占比 | 独立掷在 **0%–15%** |
| 形态 | 成簇生长（邻接膨胀），非撒盐、非 WFC |
| 部署区 | **不保护**：湖/林可落在左半盘部署列 |
| 出生点 | 若初始落点不可通行，挪到最近可通行空格 |

实现：`scripts/map/cluster_terrain_generator.gd`；沙盘经 `TacticalSandboxRoster.build_board_for_config` 调用。
