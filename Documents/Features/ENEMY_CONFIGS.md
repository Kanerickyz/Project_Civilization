# 敌人配置池 · 开局阵容

> **已实现**（轻量切片）。配置资源在 `resources/enemies/`；抽取与落子在 `tactical_sandbox_roster.gd`；状态机在 `tactical_enemy_ai.gd`。

## 范围

- 对战沙盘开局从**敌人配置池**随机抽**一套**敌方阵容，生成在右半盘（部署阶段已在场）。
- Headless / demo 棋盘固定用配置 A，保证 runner 断言稳定。

## 配置池

| 配置 | 资源 | 阵容 |
|------|------|------|
| A | `enemy_config_a.tres` | 6× 狼骑兵（`rider.tres`，攻 2 / 血 10） |
| B | `enemy_config_b.tres` | 1× 骷髅将军（`skeleton_general.tres`，攻 5 / 血 30）+ 2× 骷髅兵（`skeleton_soldier.tres`，攻 2 / 血 4） |

## 骷髅将军状态机

相位：`移动攻击 →（回血 或 召唤 2 骷髅兵）`，循环；意图角标 击/血/召。

| 意图 | 行为 |
|------|------|
| 移动攻击 | 与狼骑相同：能打则打；否则靠近至多 2 格，再尝试打 |
| 回血 | 未满血则 `hp + 2` |
| 召唤 | 在邻格空位生成至多 **2** 个骷髅兵（`skeleton_soldier.tres`，攻 2 / 血 4）；无空位则跳过 |

- 召唤出的骷髅兵**无**意图状态机，走旧启发式（能攻则攻，否则靠近）。
- 本段召唤的单位下一段对手回合才行动。
