# 卡牌行动层 · 首版

> **已实现**（完全切片）。玩家**攻击/主动技**把卡**拖到己方单位**再瞄准；**移动不经牌**（点选己方再点绿格）。对手保持脚本 AI。逻辑在 `scripts/cards/`，底栏手牌在 `scripts/ui/action_hand_fan.gd`。

## 玩家体验

己方行动段开始时，底栏出现一手卡（长方形、横向重叠）。**长按 0.35s** 看详情，**松手详情立刻消失**（卡仍在手）。攻/加强攻/护甲须**拖到己方单位**；鸣鼓换手拖到**棋盘有效格**松手即打出。随后点格/点单位瞄准（换手/护甲除外）。短按不会打出。

**移动**：点选己方单位 → 绿圈显示可达格 → 点绿格走步；每段每角色移力 = `move_range`，可分步，用尽为止。

## 牌组成

- 开局按场上**己方存活**单位生成：
  - 每人贡献 **通用攻击 1**（卡面只写「攻击」）。**无移动牌**。
  - 另按角色贡献主动技（见下表；游侠无；**鼓手 2 张**）。
- **绝不**把敌方单位卡加入玩家三库。
- 仅玩家有三库（手牌 / 牌库 / 弃牌）；对手无牌，仍按 [COMBAT.md](./COMBAT.md) AI 行动。
- **己方阵亡立刻**从手牌→牌库→弃牌减去 **攻击 1**，并减去该角色主动技（有则；含鼓手「鸣鼓换手」+「鼓舞」、爆爆「燃爆」）。对手段击杀也须清牌（结算保留目标引用，不能只靠击杀后的 `unit_at`）。**同一单位只 cull 一次**（`death_cards_culled` 幂等）；段开始燃烧扫尸体不得再减攻。敌方阵亡不影响玩家牌库。

### 主动技能卡

| 角色（贡献者） | 卡面 | 打出方式 | 效果 |
|----------------|------|----------|------|
| 鼓手 | 鸣鼓换手 | 拖到**棋盘任意有效格**松手 | 本卡进弃（本段不洗回）→ 其余手牌进弃 → 再抽 5 |
| 鼓手 | 鼓舞 | 拖到**鼓手自身** | 周围 **1** 格内其他友方各 **+1 狂暴**（战局永久，上限 15；每层伤害 ×1.2 向上取整） |
| 盾卫 | 护甲 | 拖到**任意己方**（通用，不绑） | 立刻 **+2** 护甲（可叠加；常量可调）；不进入瞄准 |
| 大剑 | 加强攻击 | 拖到**任意己方**（通用，不绑） | 选定攻击者；本次攻击额外 **+2** 伤害；瞄准同普攻 |
| 爆爆 | 燃爆 | 拖到**爆爆自身** | 选定后点红圈内单位普攻；对目标及周围施加 **3** 层燃烧 |
| 刺客 | 隐身 | 拖到**刺客自身** | 再点任意存活单位令其隐身 |
| 游侠 | — | — | **无**主动技卡 |

- **鸣鼓换手**：不要求拖到鼓手；松手在棋盘有效区即打出。打出后进弃牌；**本玩家行动段内**弃牌洗回牌库时**不**把该卡洗入牌库（避免同段再抽到）；下一段开始按 STS 正常可洗回。`bound_unit_id` 仅用于鼓手阵亡时 cull 归属。
- **鼓舞**：`bound_unit_id = wardrum`，只能拖到鼓手；不含自身；狂暴见 [UNITS.md](./UNITS.md)。
- 盾卫贡献 **1** 张通用「护甲」；大剑贡献 **1** 张通用「加强攻击」；可拖到任意己方持卡单位出牌。
- **护甲**：伤害先打护甲；若伤害 > 护甲则护甲归零，**溢出不穿血**。见 [COMBAT.md](./COMBAT.md)。
- **燃爆**：`bound_unit_id = boomling`，只能拖到爆爆；燃烧规则见 [BURN_STATUS.md](./BURN_STATUS.md)。
- 贡献者阵亡时仍 cull 该贡献的主动技（加强攻/护甲按 kind；鸣鼓换手/鼓舞/燃爆按 bound；鼓手 cull **2** 张技）。
- 加强攻/燃爆与普攻一样：再点红圈内单位（**含友方**）结算。

### 临时攻击卡（被动产出）

- 游侠**击杀**时立刻往手牌加 1 张「攻击」卡。
- **用完销毁**；结束行动弃手时也销毁；**不进**牌库/弃牌。

## 抽弃（STS 式）

- **第一次抽牌前**洗混牌库。
- 抽牌时若牌库不够：把弃牌洗回牌库再抽。
- **玩家行动段结束**：剩余手牌进弃牌（临时卡销毁），再进入对手段。
- 回到玩家段：重置己方移力池、清空攻击卡授权后，再抽手牌（玩家无段内攻次预算）。
- 默认每段抽 **5** 张。

## 卡语义与操作

| 卡 / 操作 | 使用方式 | 结算 |
|-----------|----------|------|
| **移动（无卡）** | 点选己方 → 点绿格 | 耗移力；单次路径 ≤ `move_range`；可分步至池尽 |
| 攻击 | 拖到任意己方单位 | **入队一次攻击授权**；再点红圈内**任意其他单位**（敌/友）普攻；成功后消耗队首；同单位可连拖多张再连续攻 |
| 鸣鼓换手 | 拖到棋盘任意有效格 | 本卡进弃且本段不洗回；弃光手牌再抽 5；不进入瞄准 |
| 鼓舞 | 只能拖到鼓手 | 周围 1 格其他友方各 +1 狂暴；不进入瞄准 |
| 加强攻击 | 拖到任意己方单位 | 同攻击瞄准入队，该次伤害额外 +2；成功后消耗队首 |
| 护甲 | 拖到任意己方单位 | 立刻 +2 护甲（可叠加）；不进入瞄准 |
| 燃爆 | 只能拖到爆爆 | 同攻击瞄准入队；命中后目标及周围 +3 燃烧；成功后消耗队首 |
| 隐身 | 只能拖到刺客 | 再点存活单位令其隐身；不进入攻/移瞄准 |

- **玩家无攻次数预算**：不使用 `attacked_this_side_turn` / `attack_budget`；攻击上限只在「手牌里还有对应卡、且成功拖到单位」（鸣鼓换手除外：棋盘有效格即可）。一张攻击卡结算一次；同单位连拖多张会叠加授权队列，可连续多次攻击。
- **对手 AI 不变**：仍按段内移力池与每单位每段 1 攻（`attacked_this_side_turn`），只打敌方，不经卡牌路径。
- **有效拖放**：卡进弃牌（临时卡销毁），进入瞄准或立即结算。
- **无效松手**：攻/加强攻/护甲/鼓舞/燃爆未落到可出己方单位，或鸣鼓换手未落到棋盘有效格 → 卡**回手**，不进弃。
- 触发式被动见 [UNITS.md](./UNITS.md)。

## 与回合钟

见 [TURN_CLOCK.md](./TURN_CLOCK.md)：玩家结束行动前先弃光手牌；对手段结束后回到玩家再抽。

## 界面

- 手牌：沙盘**正下方**长方形卡、横向重叠/微扇形；悬停微抬；拖拽跟手放大；松手回弹或落子后重排。主动技卡为金边深色底。
- **拖牌悬停**：当前格子高亮（可落单位 / 不可落单位 / 空白格分态）；悬停角色播 scale 选中脉冲（不改 offset/modulate，避免与 idle bob、受击闪白打架）；松手或离开清空。
- 点选己方后棋盘显示绿 overlay（有移力时）；拖攻击卡后显示红 overlay；顶栏提示当前步骤。
