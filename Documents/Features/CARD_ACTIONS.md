# 卡牌行动层 · 首版

> **已实现**（完全切片）。玩家**通用移/攻/加强攻/护甲**把卡**拖到己方单位**再瞄准；**非通用主动技**短按或拖到**技能规则格**即可打出（自动绑定施法者；无效格松手回手）；**玩家仅经移动卡移动**（不可点选角色/格子直接移动）。对手保持脚本 AI。逻辑在 `scripts/cards/`，底栏手牌在 `scripts/ui/action_hand_fan.gd`。

## 玩家体验

己方行动段开始时，底栏出现一手卡（长方形、横向重叠）。**长按 0.35s** 看详情，**松手详情立刻消失**（卡仍在手）。移/攻/加强攻/护甲须**拖到己方单位**；非通用技（鸣鼓换手/鼓舞/燃爆/隐身/万箭齐发/冲撞/恢复药水）**短按**即可打出，或拖到**技能规则格（金 overlay）**松手打出（不要求拖到对应角色）。拖到规则格外 / 手牌区 / 棋盘外松手 → **回手不消耗**。随后点格/点单位瞄准（换手/鼓舞除外）。通用卡短按不会打出。

**移动（仅卡）**：拖移动卡到己方 → 重置移力为 `move_range` 并授权 → 点绿格；**成功走一步后本卡用完**（须再打牌才能再移动）。点选角色/格子**不**进入移动。

## 牌组成

- 开局按场上**己方存活**单位生成：
  - 每人贡献 **通用移动 1 + 通用攻击 1**（卡面只写「移动」「攻击」）。
  - 另按角色贡献主动技（见下表；**鼓手 2 张**；盾卫护甲+冲撞；大剑「加强攻击」×2；游侠「万箭齐发」；医师「恢复药水」×2）。
- **绝不**把敌方单位卡加入玩家三库。
- 仅玩家有三库（手牌 / 牌库 / 弃牌）；对手无牌，仍按 [COMBAT.md](./COMBAT.md) AI 行动。
- **己方阵亡立刻**从手牌→牌库→弃牌减去 **移动 1 + 攻击 1**，并减去该角色主动技（有则；含鼓手「鸣鼓换手」+「鼓舞」、爆爆「燃爆」、游侠「万箭齐发」、盾卫「冲撞」、医师「恢复药水」×2、大剑「加强攻击」×2）。对手段击杀也须清牌（结算保留目标引用，不能只靠击杀后的 `unit_at`）。**同一单位只 cull 一次**（`death_cards_culled` 幂等）；段开始燃烧扫尸体不得再减 MOVE/攻。敌方阵亡不影响玩家牌库。

### 主动技能卡

| 角色（贡献者） | 卡面 | 打出方式 | 效果 |
|----------------|------|----------|------|
| 鼓手 | 鸣鼓换手 | 短按 / 拖规则格（全盘） | 本卡进弃（本段不洗回）→ 其余手牌进弃 → 再抽 5 |
| 鼓手 | 鼓舞 | 短按 / 拖规则格（鼓手周围 1） | 周围 **1** 格内其他友方各 **+1 狂暴**（战局永久，上限 15；每层伤害 ×1.2 向上取整） |
| 盾卫 | 护甲 | 拖到**任意己方**（通用，不绑） | 立刻 **+2** 护甲（可叠加；常量可调）；不进入瞄准 |
| 盾卫 | 冲撞 | 短按 / 拖规则格（8 向各最多 3） | 再点方向格；朝该向最多 **3** 格；路径单位（含友军）受当前攻击力并撞开；遇不可走则停前一格且自伤 **3** |
| 大剑 | 加强攻击 ×2 | 拖到**任意己方**（通用，不绑） | 选定攻击者；本次攻击额外 **+2** 伤害；瞄准同普攻 |
| 爆爆 | 燃爆 | 短按 / 拖规则格（发射带） | 选定后点红圈内单位普攻；对目标及周围施加 **3** 层燃烧 |
| 刺客（未编入当前阵容） | 隐身 | 短按 / 拖规则格（存活单位格） | 再点任意存活单位令其隐身；场上无刺客时不贡献该卡 |
| 游侠 | 万箭齐发 | 短按 / 拖规则格（发射带） | 选定后点红圈内单位；**拖牌松手落在红圈合法目标上则立刻结算**；对**目标格**及相对攻击方向**垂直左右两格**造成伤害（侧格用基础伤；远程不击退） |
| 医师 | 恢复药水 ×2 | 短按 / 拖规则格（医师周围 ≤ 攻击距离） | 再点落点格；恢复**该格一格内**（切比雪夫 ≤1，含落点）友方各 **2** 血（可含医师自身）；**拖到规则格松手可立刻按落点结算** |

- **非通用技自由打出**：`plays_on_board()` = 主动技且 `bound_unit_id != ""`。施法者由 `find_bound_caster` 解析；不在场则回手。**拖放**须落到 `release_preview_cells`（规则格）；格外/无格松手回手。**短按**仍可不经落点直接打出。
- **拖牌预览**：高亮技能规则格（换手=全盘；鼓舞=鼓手周围 1；燃爆/万箭=发射带；冲撞=8 向各最多 3 格；隐身=存活单位格；恢复药水=医师周围 ≤ attack_range）；悬停目标格时从施法者到该格画 **STS 风格二次贝塞尔曲线箭头**（金=规则格内可松，红=格外将回手）。
- **鸣鼓换手**：打出后进弃牌；**本玩家行动段内**弃牌洗回牌库时**不**把该卡洗入牌库；下一段开始按 STS 正常可洗回。`bound_unit_id` 用于鼓手阵亡时 cull 归属。
- **鼓舞**：结算始终以鼓手为中心；不含自身；狂暴见 [UNITS.md](./UNITS.md)；生效时受益友方飘 `+N狂`。
- 盾卫贡献 **1** 张通用「护甲」+ **1** 张绑定「冲撞」；大剑贡献 **2** 张通用「加强攻击」；医师贡献 **2** 张绑定「恢复药水」；可拖到任意己方持卡单位出牌（冲撞/药水除外）。
- **护甲**：立刻叠甲并飘 `+N甲`；伤害先打护甲；若伤害 > 护甲则护甲归零，**溢出不穿血**。见 [COMBAT.md](./COMBAT.md)。
- **冲撞**：见 [KNIGHT_CHARGE.md](./KNIGHT_CHARGE.md)。
- **燃爆**：燃烧规则见 [BURN_STATUS.md](./BURN_STATUS.md)。
- **万箭齐发**：主目标走普攻结算（远程，**不**击退）；侧格有单位则各吃一发基础伤害（可友方可敌方；不含攻击者与主目标本人）。
- 贡献者阵亡时仍 cull 该贡献的主动技（加强攻/护甲按 kind；鸣鼓换手/鼓舞/燃爆/万箭齐发/冲撞/恢复药水按 bound；鼓手 cull **2** 张技；大剑 cull 加强攻 **2**；医师 cull 恢复药水 **2**；盾卫 cull 护甲+冲撞）。
- 加强攻/燃爆/万箭齐发与普攻一样：再点红圈内单位（**含友方**）结算。
- **恢复药水**：短按进入金圈瞄准；拖到规则格松手立刻按落点结算；治疗不抬上限。

### 临时攻击卡（工具）

- `add_ephemeral_attack_to_hand` 仍可发临时「攻击」卡（用完销毁、不进三库）；游侠击杀被动为「猎召」（邻格友军尝试攻击），**无**出牌抽牌 / 击杀掉临时攻卡（箭袋已删，勿恢复）。

## 抽弃（STS 式）

- **第一次抽牌前**洗混牌库。
- 抽牌时若牌库不够：把弃牌洗回牌库再抽。
- **玩家行动段结束**：剩余手牌进弃牌（临时卡销毁），再进入对手段。
- **手牌打完自动结束**：结算完成后若手牌为空，自动结束行动进入对手段（不跳过对手段、不直接进入下一玩家段）。须等鸣鼓换手抽牌、盾卫友方死亡抽牌等补牌结算后再判；移/攻/隐身/冲撞/恢复药水瞄准未点目标前不触发（卡已离手但仍待结算）。**进对手段前**须等技能提示、飘字队列、反应攻击、击杀剪影等战斗表现播完。
- 回到玩家段：清零己方移力、清空移动/攻击卡授权后，再抽手牌（玩家无段内攻次预算；移力仅经移动卡获得）。
- **回合开始抽牌表现**：逻辑一次抽满后，底栏 UI **逐张**从右侧飞入（杀戮尖塔式）；动画期间锁输入，结束后才可打牌。开战确认后第一手同样。
- 默认每段抽 **5** 张。

## 卡语义与操作

| 卡 / 操作 | 使用方式 | 结算 |
|-----------|----------|------|
| 移动 | 拖到任意己方单位 | 重置移力为 `move_range` 并授权；再点绿格；**成功一步后本卡用完** |
| 攻击 | 拖到任意己方单位 | **入队一次攻击授权**；再点红圈内**任意其他单位**（敌/友）普攻；成功后消耗队首；同单位可连拖多张再连续攻 |
| 鸣鼓换手 | 短按 / 拖规则格 | 本卡进弃且本段不洗回；弃光手牌再抽 5；不进入瞄准 |
| 鼓舞 | 短按 / 拖规则格 | 自动绑鼓手；周围 1 格其他友方各 +1 狂暴；不进入瞄准 |
| 加强攻击 | 拖到任意己方单位 | 同攻击瞄准入队，该次伤害额外 +2；成功后消耗队首 |
| 护甲 | 拖到任意己方单位 | 立刻 +2 护甲（可叠加）；不进入瞄准 |
| 燃爆 | 短按 / 拖规则格 | 自动绑爆爆后进入攻击瞄准；命中后目标及周围 +3 燃烧 |
| 万箭齐发 | 短按 / 拖规则格 | 自动绑游侠后进入攻击瞄准；松手落在红圈合法目标则立刻结算；命中后目标 + 攻击方向垂直左右两格受伤 |
| 冲撞 | 短按 / 拖规则格 | 自动绑盾卫；再点方向格冲撞最多 3 格 |
| 隐身 | 短按 / 拖规则格 | 自动绑刺客；再点存活单位令其隐身 |
| 恢复药水 | 短按 / 拖规则格 | 自动绑医师；再点落点格治疗该格一格内友方各 +2 血；拖到规则格可立刻结算 |

- **玩家无攻次数预算**：不使用 `attacked_this_side_turn` / `attack_budget`；攻击上限只在「手牌里还有对应卡、且成功拖到单位」（非通用技除外：规则格拖放或短按即可）。一张攻击卡结算一次；同单位连拖多张会叠加授权队列，可连续多次攻击。
- **对手 AI 不变**：仍按段内移力池与每单位每段 1 攻（`attacked_this_side_turn`），只打敌方，不经卡牌路径。
- **有效打出**：卡进弃牌（临时卡销毁），进入瞄准或立即结算。
- **无效松手**：通用移/攻/加强攻/护甲未落到可出己方单位；非通用技施法者不在场、或拖放落点不在规则格（含手牌区/棋盘外）→ 卡**回手**，不进弃。
- 触发式被动见 [UNITS.md](./UNITS.md)。

## 界面

- 手牌：沙盘**正下方**长方形卡、横向重叠/微扇形；悬停微抬；拖拽跟手放大；松手回弹或落子后重排。主动技卡为金边深色底。玩家段开始时逐张飞入（见上）。
- **拖牌悬停**：当前格子高亮（可落单位 / 不可落单位 / 空白格分态）；悬停角色播 scale 选中脉冲（不改 offset/modulate，避免与 idle bob、受击闪白打架）；松手或离开清空。
- **伤害/触发链路预览**：技能/治疗卡拖到规则格/目标时试算整条结算链（伤/疗/击退/被动等），头顶血条叠预览色并弹出链路文案；攻击卡在授权后瞄准悬停目标时同样预览；移动卡拖到己方显示「移力→N · 点绿格」并叠可达绿格。
- **非通用技拖牌**：金 overlay 标可释放/规则格；施法者→悬停格 STS 曲线箭头。
- 打出移动卡后棋盘显示绿 overlay；拖攻击卡后显示红 overlay；顶栏提示当前步骤。点选单位仅查看，不进入移动。
