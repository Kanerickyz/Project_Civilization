# 燃烧状态 · 爆爆

> **已实现**（轻量切片）。单位层数在 `TacticalUnitInstance.burn_stacks`；施加/结算在 `TacticalBoard`。

## 规则

- **层数**：单位持有 `burn_stacks`；可叠加。
- **每方行动段开始**（玩家或对手进入行动时）：对所有燃烧单位 **先造成 = 当前层数 的伤害**，再 **减 1 层**（至 0 清除）。
- 燃烧伤害走 `apply_damage`（可触发受伤被动、击杀、死亡被动）。
- 空格不持久化燃烧玩法层数；只对当时站在范围内的存活单位叠层。

## 来源

| 来源 | 范围 | 层数 |
|------|------|------|
| 爆爆主动技「燃爆」命中 | 目标格及周围（切比雪夫 ≤1），排除攻击者 | 3 |
| 爆爆被动「爆燃」死亡 | 所在格及周围（切比雪夫 ≤1） | 3 |

## 视觉（纯 2D）

- **单位燃烧层数**：头顶旁橙色徽章 `◆燃N`（`N` = 当前层数）；层数为 0 时隐藏。
- **点燃地块标记**：燃爆/爆燃 AoE 范围内全部格子（含空格）显示橙色菱形火标并轻脉冲；下一段燃烧结算后收束，仅保留仍有燃烧层数的单位脚下格。
- 不使用 Light2D / 3D 灯。

## 与湖泊

- 湖格不进入点燃标记；站在湖上的单位不受燃烧施加。
- 燃烧单位**进入湖格**时清除层数。见 [LAKE_FOREST.md](./LAKE_FOREST.md)。
