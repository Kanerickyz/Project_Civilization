# 有限六边形地图 · WFC 预生成 · 战略迷雾 · 3D 俯视

已实现（沙盘接入）。玩家可见行为以本文件与代码为准。

## 规则

- 地图为**有限**六边形盘（默认轴向见 `resources/map/map_config.tres`，可改）。
- 开局用 **WFC（波函数坍塌）预生成整图**地形；不是点一下才生成一格。
- 地形大类（第一版）：海洋、沙滩、草原、森林、丘陵、山地、沙漠、沼泽、雪原。邻接约束保证常见过渡（如海—滩—陆）；外圈偏海洋、次外偏海滩；失败时有限次重试，并做中心陆联通与外圈海占比校验。
- 默认从**几何中心**开局。初始揭开约 **7** 格（中心 + 六邻），且该簇强制为可站陆地（不含海洋/沙滩/山地）。
- 其余格子盖**整局战略迷雾**。点击与**己方已揭开格邻接**的迷雾格可揭开。
- 迷雾**分边**（玩家 / 对手各有一份已揭开集合）——本切片默认；可改。
- 本切片**保留点雾揭开**（尚无单位）。单位落地后是否取消点雾留给后续，不在本切片做单位。

## 镜头与表现

- **视角**：约 **45°** 战略俯视（Civ V/VI 类），3D 六边棱柱占位地形（高度/色区分大类）。
- **操作**：拖拽平移浏览已解锁区域；**滚轮可适度缩放**（手动）。
- **禁止**：随解锁自动放大可扫范围。
- 镜头夹紧在已揭开格附近；固定俯角，不随迷雾推进改默认缩放。

## 与回合钟

- 「结束行动」仍走 `TurnClock`。本切片默认：仅**玩家行动**时可点雾揭开（可改）。
