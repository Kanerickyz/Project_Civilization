# 战斗与胜负 · 基础循环

> **已实现**（完全切片）。普攻在 `scripts/units/tactical_combat.gd`，对手 AI 在 `tactical_enemy_ai.gd`。

## 普攻

- 玩家须把**攻击卡、加强攻击卡或燃爆卡拖到**己方攻击者（燃爆只能拖到爆爆），再点**红圈**内单位发动（**可友方可敌方**；见 [CARD_ACTIONS.md](./CARD_ACTIONS.md)）。燃烧状态见 [BURN_STATUS.md](./BURN_STATUS.md)。
- **玩家**：无段内攻击次数预算（无 `attack_budget` / 不使用 `attacked_this_side_turn`）。一张攻击卡入队一次攻击；同单位可连拖多张叠加后再连续攻。加强攻击额外 +2 伤害（随该次入队）。与移动授权独立。
- **对手 AI**：每单位每方行动段最多普攻 1 次（`attacked_this_side_turn`），只选敌方。
- 伤害 = `apply_frenzy_to_damage(attack_power + 加强额外)`（狂暴每层 ×1.2 向上取整；见 [UNITS.md](./UNITS.md)）。**护甲**：有护甲时伤害先打护甲；若伤害 > 护甲则护甲归零，溢出**不**扣 HP；无护甲才扣血。「受伤」被动仅在实际扣血时触发。攻击前播放冲刺 Tween；命中时短暂挂纯 2D flash shader 使受击角色**完全纯白**并抖动，结束后卸 material 恢复默认 Sprite2D 亮度；并用中文字体飘出伤害数字（同格多条含被动飘字串行排队，相邻间隔 0.4s）；死亡与常驻 HP/护甲/狂暴读数协调。**击杀**时另闪全屏红斜横带 + **被击杀单位精灵黑剪影**冲击（剪影锚在死亡单位屏幕位，非屏心；纯 2D `_draw` / `draw_texture_rect` 乘黑；剪影屏幕尺寸与棋盘单位一致，最近邻 + 整像素对齐以减锯齿；短暂淡出；见 `scripts/ui/kill_impact_fx.gd`）。**同批多死**（同次攻击结算 / 同 tick 燃烧等）：击杀效果一次同闪，**多枚剪影各锚死亡位**。**猎召 / 追斩等反应攻击**与被动触发：先播技能名/单位抖动，再排队冲刺与伤害/数值飘字；群体增益同类数值同步弹出、不同类按序；溅射多段亦串行，相邻间隔 **0.4s**，避免一瞬间多段结算看不清。己方阵亡时玩家库减通用移/攻各 1，并按贡献者减主动技（鸣鼓换手/鼓舞/燃爆绑角色；护甲通用 cull 1；大剑加强攻通用 cull 2；医师恢复药水 cull 2）；敌方阵亡不改玩家库。
- **近战**（邻格 / `attack_range≤1`，含敌方）命中后沿攻击方向击退 1 格；落点不可走则本次改为最终伤害×1.2（ceil）；落点有单位则对其额外 1 伤；可退时短 Tween 推开。**远程不推**。见 [ATTACK_KNOCKBACK.md](./ATTACK_KNOCKBACK.md)。
- **游侠**攻击带 `attack_range_min` 死区：邻格（距离 ≤1）不可作为攻击目标。

## 移动

- **移动卡**（见 [CARD_ACTIONS.md](./CARD_ACTIONS.md)）：拖到己方重置移力并授权一次；成功走一步后本卡用完。不可点选角色/格子直接移动。
- **绿圈**仅在移动卡授权后且剩余移力 > 0 时，按可达空格显示。
- 对手 AI 不走卡牌路径：进入对手段时重置移力池，池尽不可再移。

## 胜负

- 某阵营全部单位 `hp <= 0` → 该方失败，对方胜利。
- 沙盘弹出简要结算，可返回主菜单。

## 对手 AI

- 玩家点「结束行动」后进入对手行动段；AI **按单位 id、再按格坐标**排序，每个红方单位依次行动；移动/攻击/回血/加攻 Tween **串行**播放，全部单位完成后自动结束行动，回合数 +1，回到玩家。
- **狼骑兵**（`rider`）走行为状态机与意图角标，见 [WOLF_CAVALRY_INTENT.md](./WOLF_CAVALRY_INTENT.md)：每单位每段执行**一个**可解析意图（攻击→移动→回血|加攻循环；不可行则跳过；**攻击距离 1** 邻格内已能打到则移动改为攻击）。点选时除绿/红行动格外，叠加下回合意图虚影（路径/目标/回血加攻提示）。
- 进入对手段时重置对手移力池与 `attacked_this_side_turn`；进入玩家段清零己方移力、清空移动/攻击卡授权后抽牌（玩家无段内攻次预算；移力仅经移动卡获得）。
