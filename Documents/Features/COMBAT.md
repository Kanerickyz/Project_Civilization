# 战斗与胜负 · 基础循环

> **已实现**（完全切片）。普攻在 `scripts/units/tactical_combat.gd`，对手 AI 在 `tactical_enemy_ai.gd`。

## 普攻

- 玩家须把**攻击卡或加强攻击卡拖到**己方攻击者，再点**红圈**内单位发动（**可友方可敌方**；见 [CARD_ACTIONS.md](./CARD_ACTIONS.md)）。
- **玩家**：无段内攻击次数预算（无 `attack_budget` / 不使用 `attacked_this_side_turn`）。一张攻击卡授权一次攻击；可打多张再攻。加强攻击额外 +2 伤害。与移动授权独立。
- **对手 AI**：每单位每方行动段最多普攻 1 次（`attacked_this_side_turn`），只选敌方。
- 伤害 = 当前 `effective_attack()`（含本场攻加成）+ 加强攻额外。攻击前播放冲刺 Tween，受击/死亡与 HP popup 协调。己方阵亡时玩家库减通用移/攻各 1，并按贡献者减主动技（鸣鼓换手绑角色；加强攻为通用卡仍 cull 1）；敌方阵亡不改玩家库。

## 移动

- **玩家无移力池**（见 [UNITS.md](./UNITS.md)）。须把**通用移动卡拖到**己方行动者：授权后点一次绿格完成移动（路径步数 ≤ `move_range`）；**一张卡只走一次**，成功后清授权。再打一张移动卡可再移。
- **绿圈**仅在该单位已获移动授权、且 `move_range` 内可达的空格显示。
- 对手 AI 不走卡牌路径：进入对手段时重置移力池，池尽不可再移。

## 胜负

- 某阵营全部单位 `hp <= 0` → 该方失败，对方胜利。
- 沙盘弹出简要结算，可返回主菜单。

## 对手 AI（最小）

- 玩家点「结束行动」后进入对手行动段；AI **按单位 id 排序**，每个红方单位依次：在移力池内能攻则攻（优先低 HP），否则逐步靠近最近蓝方（按绕墙后的路径距离）；每步移动/攻击 Tween **串行**播放，全部单位完成后自动结束行动，回合数 +1，回到玩家。
- 进入对手段时重置对手移力池与 `attacked_this_side_turn`；进入玩家段清空移动/攻击卡授权后抽牌（玩家无段内攻次预算）。
