# 开战前部署 · 左半盘站位

> **已实现**（轻量切片）。沙盘加载先进部署，确认后再开战。

## 玩家能做什么

- 进入对战沙盘后先进入**部署阶段**（尚未抽手牌、未结算开战触发）。
- **拖**己方单位（立绘跟手）到合法**己方部署区**调整占位；可与另一名己方单位换位；非法落点弹回。
- 敌方单位开局已生成在右半盘，不可拖动、不可占其格。
- 点「开始战斗」后进入正常第 1 回合玩家行动（抽手牌、开战/段开始触发按既有规则）。

## 规则

| 项 | 约定 |
|----|------|
| 己方部署区 | 棋盘左半列：`x < grid_width / 2`（10×8 为列 0–4；8×10 为列 0–3），且可通行（不含边缘 void） |
| 落点 | 空格，或己方单位所占格（换位） |
| 禁止 | 敌方格、城墙/树林等不可通行、右半盘（湖可部署；生成不保护部署区） |
| 敌方开局 | 右半盘随机可通行格生成 6 狼骑兵（部署阶段已在场） |
| 部署落位 | 不耗移力、不触发「移动结束」被动 |
| 确认前 | 手牌不可用；「结束行动」隐藏，改为「开始战斗」 |
