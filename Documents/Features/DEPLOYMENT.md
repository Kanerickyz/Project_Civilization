# 开战前部署 · 全图站位

> **已实现**（轻量切片）。沙盘加载先进部署，确认后再开战。

## 玩家能做什么

- 进入对战沙盘后先进入**部署阶段**（尚未抽手牌、未结算开战触发）。
- **拖**己方单位（立绘跟手）到**全图**可通行格调整占位；可与另一名己方单位换位；非法落点弹回。
- 棋盘显示敌方**潜在生成点**（6 只狼骑兵虚影）；部署阶段**不生成**敌方单位。
- 友方初始站位随机；随后随机敌潜在点。若玩家拖位覆盖某潜在点，该点**重随**到空格。
- 点「开始战斗」后：在潜在点生成狼骑兵 → 进入正常第 1 回合玩家行动（抽手牌、开战/段开始触发按既有规则）。

## 规则

| 项 | 约定 |
|----|------|
| 己方部署区 | **全图**可通行格 |
| 落点 | 空格，或己方单位所占格（换位） |
| 禁止 | 敌方已占格（开战前无）、城墙/树林等不可通行 |
| 敌潜在点 | 6 格；开战前仅虚影；确认开战才生成 |
| 部署落位 | 不耗移力、不触发「移动结束」被动 |
| 确认前 | 手牌不可用；「结束行动」隐藏，改为「开始战斗」 |
