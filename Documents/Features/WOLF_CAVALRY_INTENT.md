# 敌方狼骑兵 · 行为状态机与意图

> **已实现**（轻量切片）。逻辑在 `scripts/units/tactical_enemy_ai.gd`；意图角标在 `grid_board_view.gd`。

## 范围

- 仅敌方 `rider`（狼骑兵）；每只单位**各自独立**相位。
- 单位 UI 显示**下一回合将执行**的意图（◆攻 / ◆移 / ◆血 / ◆加），挂在头顶血攻读数偏左，不挡中央读数与右侧燃烧角标。

## 相位顺序

`攻击 → 移动 →（恢复 2 血 或 提高 2 攻，随机其一）`，循环。

| 意图 | 条件 | 行为 |
|------|------|------|
| 攻击 | 射程内有可打玩家（现有射程 / 阻挡 / 树林 LOS） | 打**最近**可打玩家（同距取低 HP） |
| 移动 | 可靠近；若**已能打到**玩家则**改为攻击** | 向最近玩家靠近至多 **2** 格 |
| 回血 | 未满血 | `hp + 2`（不超过上限） |
| 加攻 | 一般总可执行 | `atk_bonus + 2` |

- **开战**：意图为攻击（图标显示 ◆攻）。
- **不符合条件则跳过**到下一状态，继续判定，直到找到可执行项。
- 移动相位进入「回血|加攻」时（执行后推进，或移动不可行而跳过）**随机二选一**写入下一意图。
- 回血时已满血：按跳过处理，转到攻击。

## 整圈兜底

若从当前意图起绕一圈仍无任何可执行行为：本回合**待机**，并将意图**推进一档**（避免永久卡在同一意图）。日志记「无可行行为，待机」。

## 非本切片

- 不改玩家卡牌、部署或其它兵种 AI。
- 非 `rider` 的敌方若存在，仍走旧启发式（能攻则攻，否则靠近）。
