# 地图缩圈 · 永久危险区

> **已实现**（轻量切片）。逻辑在 `TacticalBoard`；沙盘段开始同步与结算；视觉在 `GridBoardView`。

## 规则

- **起始**：从第 **5** 回合起，每进入新的回合数（`TurnClock.turn`）缩一层。
- **缩圈方式**：从**四个角**向内崩塌——`corner_distance == stage-1` 的层永久标为危险区。  
  `corner_distance` = 到最近角的 Chebyshev 距离：  
  `min(max(x,y), max(W-1-x,y), max(x,H-1-y), max(W-1-x,H-1-y))`。  
  第 1 层仅四角；其后各角呈方形楔块向内扩展。**不是**四边整边外环缩进。
- **全局次数 n**：`collapse_stage`；第 5 回合 n=1，第 6 回合 n=2，…（`n = turn - 4`）。
- **危险区伤害**：站在任意已崩塌危险格上的单位，在**该方行动段开始前**结算一次；伤害 = **2^(n-1)**（n=1→1，n=2→2，n=3→4，…）。敌我各自结算本方单位，不跨方。
- 危险格**可通行**；不改地形类型。崩塌格永久保留。

## 时序（与燃烧同拍）

1. `sync_map_collapse(turn)`（按回合数补齐层，通常在玩家段进入新回合时扩一层）
2. `process_danger_ticks(faction)`（仅本方）
3. `process_burn_ticks(faction)`（仅本方）
4. 段开始被动 → 本方意图/出牌

## 视觉

- 危险格：整格淡紫罩（overlay `d`）+ 深紫空洞菱形标记轻脉冲（独立于点燃橙标）。四角楔块向内生长，边心中段更晚崩。
