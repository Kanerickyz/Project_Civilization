# 游戏愿景 — 小规模、快节奏的文明式战棋

> 设计方向的入口。**已经能玩到的行为**以代码和 [Features/TURN_CLOCK.md](./Features/TURN_CLOCK.md) 为准。本文其余部分是方向，不是已实现功能。

## 一句话

玩家在一张小地图上，用比文明正作少得多的回合，完成开拓、发展和战棋交锋。

## 和文明的关系

借鉴文明的是这些体验：

- 回合制，轮到谁谁行动
- 地图是格子，单位站在格子上
- 定居点负责发展，单位负责打仗和开拓
- 一局里要在扩张、生产和打仗之间做取舍

比文明正作更小、更快，指的是：

- 地图小，先只做玩家对一个对手
- 系统少。当前切片不展开宗教、文化胜利、世界议会和长科技树
- 一局应远短于传统文明的数小时。具体回合上限留给后续数值切片，不在这里定死

## 现在已经落地

| 玩家能看到的 | 实际规则 |
|--------------|----------|
| 主菜单进入沙盘 | 场景切换 |
| 有限六边形地图与战略迷雾 | WFC 预生成整图；中心约 7 格已揭开；点邻雾揭开；拖拽镜头。见 [Features/HEX_MAP.md](./Features/HEX_MAP.md) |
| 「结束行动」 | 回合钟，见 [Features/TURN_CLOCK.md](./Features/TURN_CLOCK.md) |

没有城市产出、科技、外交、单位移动或战斗结算。

## 下一刀的玩家体验（未实现）

下一刀要让玩家在小地图上移动单位，并分出一次短交锋。定居点、生产和胜利条件在那之后再定规格。动笔写 Feature 之前先用 `design-brainstorm`，不要在愿景里把未立项系统展开成章节。

## 边界

这不是自走棋：没有商店养队，没有开战纯观战，没有招募和三合一。

## 术语

| 术语 | 含义 |
|------|------|
| 回合 | 玩家与对手各行动一次后，回合数加一 |
| 行动方 | 当前可以结束行动的一方：玩家或对手 |
| 沙盘 | 主菜单进入的试玩界面（现为有限六边地图） |
| 格子 | 地图上的一格；当前为六边形 |
