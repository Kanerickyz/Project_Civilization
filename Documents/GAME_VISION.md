# 游戏愿景 — 小地图战术战棋

> 设计方向的入口。**已经能玩到的行为**以代码和 [Features/TURN_CLOCK.md](./Features/TURN_CLOCK.md) 为准。本文其余部分是方向，不是已实现功能。

## 一句话

玩家在一张小方格盘上，用较短回合完成站位、交锋与胜负（具体胜利条件后续定）。

## 和 4X / 自走棋的区别

- **是**：回合制、格子地图、单位站在格子上、先只做玩家对一个对手。
- **不是**：大地图 4X 开拓、长科技树、宗教/文化胜利、世界议会。
- **不是**自走棋：没有商店养队、纯观战战斗、胜后招募或三合一。

## 现在已经落地

| 玩家能看到的 | 实际规则 |
|--------------|----------|
| 主菜单进入对战沙盘 | 场景切换 |
| 3D 斜 45° 正交方格盘 + 2D 占位单位 | 见 [Features/GRID_BOARD.md](./Features/GRID_BOARD.md) |
| 「结束行动」 | 回合钟，见 [Features/TURN_CLOCK.md](./Features/TURN_CLOCK.md) |

没有单位移动、战斗结算、城市或科技。

## 下一刀的玩家体验（未实现）

下一刀让玩家在方格上**移动单位**并完成一次短交锋。动笔写 Feature 前先用 `design-brainstorm`，不要把未立项系统写进规格。

## 术语

| 术语 | 含义 |
|------|------|
| 回合 | 玩家与对手各行动一次后，回合数加一 |
| 行动方 | 当前可以结束行动的一方 |
| 沙盘 | 主菜单进入的对战界面（方格盘） |
| 格子 | 棋盘上一格方格 |
