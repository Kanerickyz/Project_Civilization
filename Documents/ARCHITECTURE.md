# 架构

初始化工程。除回合钟外，下面的系统划分是以后的落点，不是已实现模块。

## 当前状态

- 主菜单 → 沙盘占位
- `TurnClock`：玩家与对手交替
- `GameSettings`：音量与全屏会写入 `user://settings.cfg`，界面上还不能改
- 没有地图数据、单位数据、战斗或存档对局

## 目录

| 路径 | 职责 |
|------|------|
| `scenes/main/` | 主菜单、沙盘 |
| `scripts/core/` | 与界面无关的规则（现为回合钟与加载烟测） |
| `scripts/ui/` | 界面脚本 |
| `scripts/autoload/` | 全局设置 |
| `resources/` | 以后的 `.tres` 数值 |
| `assets/` | 字体、图、声音 |
| `tools/` | 安装 Godot、加载烟测、test runner |
| `Documents/` | 愿景、规格、工作流 |
| `.cursor/` | 角色、规则、技能 |

## 系统划分（规划）

| 系统 | 职责 | 状态 |
|------|------|------|
| 回合钟 | 谁在行动、第几回合 | **已实现** |
| 地图 | 格子、占用、移动 | 未做 |
| 单位 | 站在格子上的棋子 | 未做 |
| 定居点 | 产出与发展 | 未做 |
| 战斗 | 相邻或进入敌格时的结算 | 未做 |
| 界面 | 菜单、地图 HUD、回合条 | 菜单和占位沙盘已有 |

新增系统时先写 Feature，再落代码。不要为了「以后可能像文明」先搭空管理器。

## 不要从自走棋工程搬过来的东西

那个项目的商店、牌库、招募、技能效果栈和战斗事件总线属于另一种游戏。本仓库不建立对应目录，也不把那些名词写进规格。需要新系统时按本页的划分命名。
