# UI 字体

界面默认字体：`res://resources/ui/ui_font.tres`（FontVariation）。

| 文件 | 作用 |
|------|------|
| `NotoSans-Regular.ttf` | 拉丁字母与数字（OFL Noto Sans） |
| `DroidSansFallbackFull.ttf` | 中文回退 |
